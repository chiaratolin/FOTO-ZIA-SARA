# Mary's Home Verona

Landing autonoma per Mary's Home Verona (host: Ornella, Via Gardesane 44, Verona), costruita sulla stessa base grafica di Sara's Holiday Home ma completamente indipendente: ha i suoi `index.html`, `css/`, `js/`, `images/`, privacy e cookie policy. Si pubblica caricando questa cartella come sito a sé (su Vercel: nuovo progetto con Root Directory `marys-home-verona`).

- Palette ricavata dalle foto: blocco `:root` di `css/style.css`
- Numero WhatsApp/telefono: `js/main.js`
- Foto: `images/` (ritagliate dagli screenshot e ridimensionate a 1400 px)

Da fare quando ci sarà il dominio: canonical, hreflang e og:image assoluta in `index.html`.
